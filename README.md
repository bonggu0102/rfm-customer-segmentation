# RFM 고객 세분화 분석

온라인 고객 데이터를 이용해 고객별 구매 행동을 RFM 기준으로 나누고, 등급별 특징과 마케팅 활용 방향을 정리한 프로젝트입니다.

## 프로젝트 개요

- 분석 목적: 고객 가치에 따라 고객군을 구분하고 등급별 구매 특성을 파악
- 분석 대상: 전처리 후 고객 2,229명
- 사용 도구: Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook
- 데이터: 캐글 데이터

## 전처리

- 연 소득 결측값 24개를 평균값으로 대체했습니다.
- 기준 연도인 2023년에서 출생 연도를 빼 고객 나이를 계산했습니다.
- 115세 이상인 고객 3명을 이상값으로 보고 제외했습니다.
- 연 소득은 IQR 범위를 벗어난 고객 8명을 제외했습니다.
- 6개 품목의 구매 금액을 합해 총 구매 금액을 만들었습니다.
- 구매 빈도는 웹 구매와 매장 구매 횟수의 합으로 계산했습니다.
- 할인 구매 횟수는 채널 구매와 중복될 가능성이 있어 RFM 산식에서 제외하고 고객 성향 분석에 따로 사용했습니다.

## RFM 기준

| 지표 | 정의 | 점수 방향 |
| --- | --- | --- |
| Recency | 마지막 구매 후 경과일 | 짧을수록 높은 점수 |
| Frequency | 웹 구매 횟수 + 매장 구매 횟수 | 많을수록 높은 점수 |
| Monetary | 전체 품목 구매 금액의 합 | 클수록 높은 점수 |

각 지표는 `pd.qcut`을 이용해 4개 구간으로 나누었습니다. 최종 RFM 점수는 Recency 0.2, Frequency 0.4, Monetary 0.4의 가중치를 적용하고 3개 고객 등급으로 구분했습니다.

## 주요 결과

![RFM 등급별 고객 수와 매출 기여도](images/rfm_summary.png)

| RFM 등급 | 고객 수 | 고객 비중 | 매출 비중 | 평균 Recency | 평균 구매 횟수 | 평균 구매 금액 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1등급 | 873명 | 39.2% | 5.4% | 54.7일 | 5.0회 | 약 10.8만 원 |
| 2등급 | 621명 | 27.9% | 31.0% | 53.7일 | 10.4회 | 약 87.5만 원 |
| 3등급 | 735명 | 33.0% | 63.7% | 38.6일 | 15.4회 | 약 152.0만 원 |

- 3등급 고객은 전체 고객의 33.0%지만 매출의 63.7%를 차지했습니다.
- 3등급은 평균 구매 횟수와 평균 구매 금액이 모두 가장 높았습니다.
- 등급이 높아질수록 주류 매출 비중이 커졌습니다.
- 혼인 상태의 구성 비율은 등급별 차이가 크지 않았습니다.

## 고객 성향 분석

![RFM 등급별 품목 매출 구성](images/product_mix.png)

3등급의 주류 매출 비중은 51.3%로 1등급의 41.9%보다 높았습니다. 반면 잡화 비중은 1등급 16.6%에서 3등급 6.2%로 낮아졌습니다.

![구매 채널과 할인 구매 횟수](images/purchase_behavior.png)

모든 등급에서 매장 구매가 웹 구매보다 많았습니다. 할인 구매 횟수는 2등급이 평균 2.66회로 가장 높아 RFM 등급과 단순히 비례하지 않았습니다. 할인 반응은 RFM 점수와 별개의 고객 성향으로 보는 편이 적절합니다.

## 활용 방향

- 3등급: 주류 관련 혜택과 VIP 캠페인 우선 검토
- 2등급: 할인 반응을 활용한 상위 등급 전환 캠페인 검토
- 구매 금액이 크지만 Recency가 긴 고객: 재구매 유도 캠페인 대상자로 별도 확인

## 분석의 한계

- 거래별 날짜가 없어 구매 주기와 재구매율은 확인하지 못했습니다.
- RFM 구간은 현재 고객 분포에 따른 상대적인 기준입니다.
- 할인 구매가 웹·매장 구매에 포함되는지는 데이터 정의만으로 확인하기 어렵습니다.
- RFM 가중치는 탐색적으로 정한 값이므로 실제 캠페인 성과를 이용한 검증이 필요합니다.
